# MyStratos landing page

This is a standalone local-only landing/onboarding website.

It does not import or modify the existing frontend, backend, extension, LinkedIn, or Indeed code.

The YouTube walkthrough video ID is configured in:

```text
scripts/config.js
```

## Run locally

From this folder:

```powershell
python -m http.server 5199
```

Then open:

```text
http://127.0.0.1:5199
```
