Install and start tracking

Set up the extension in a few simple steps.

This is written for a first-time user. They should understand what MyStratos does before opening the live dashboard.

1

Download from GitHub

Go to the MyStratos GitHub page and download or clone the extension folder.

2

Open Chrome Extensions

Open chrome://extensions, enable Developer mode, and choose “Load unpacked”.

3

Select the extension folder

Pick the MyStratos extension folder. The extension icon appears in Chrome.

4

Sign in and apply

Sign in with Google, open LinkedIn or Indeed, and apply. Confirmed jobs appear in MyStratos.

Ready after installation

If you have installed the extension, try it out now.

Open the live MyStratos workspace, sign in with Google, and test a LinkedIn or Indeed application flow from the same browser profile.
